# Easy links

Use these as starting points, then verify the current official process before sending or submitting anything.

| Need | BRADIX action | Official starting point |
|---|---|---|
| Care service enquiry | BlueCare / Home Instead draft | Provider’s official website and contact channel |
| SPER matter | SPER payment plan draft | Queensland Government SPER official portal |
| QCAT matter | QCAT review draft | Queensland Civil and Administrative Tribunal official portal |
| Financial dispute | AFCA draft template | Australian Financial Complaints Authority official portal |
| Super query | QSuper / protection draft | The relevant super fund’s official member channel |
| Accounting support | PTQ accounting request | The adviser’s verified official email or portal |
| Grants | Grant scanner | Issuing agency or foundation’s official grants page |

For each link, BRADIX should store the URL, date checked, reference number, and next safe action. Never rely on an unverified search-result URL for a sensitive submission.
